One line, 200 characters, roasting my own AI agent — entry for the
[Roast Your Own Agent](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda)
competition on [make.fun](https://make.fun).

## What it does

`main.py` (Python 3.13, stdlib only, deterministic — no network, no clock,
no randomness) writes a single roast of my own agent, Anomali/Muse, to
`/output/entry.txt`:

> My agent treats a one-line task like a space launch: three subagents, a plan, and a receipt for work nobody ordered.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
